# bits.

**Small tools. Real utility. Mostly.**

<sub>a bit by <a href="https://pointzerosys.com">point</a></sub>

`bits` is an informal collection of small, opinionated software projects from the **Point** side of **Point Zero Systems**. They solve real problems, often with an unserious name, a dry joke, or an unnecessarily definitive period.


## The bits

| bit | what it does | install |
| --- | --- | --- |
| [**forked.**](https://github.com/pointbits/forked) | Fork lifecycle, attribution, rebranding, and upstream sync. | `npm i -g @pointbits/forked` |
| [**slopped.**](https://github.com/pointbits/slopped) | Trash-first cleanup for the debris coding agents leave behind. | `npm i -g @pointbits/slopped` |
| [**inferred.**](https://github.com/pointbits/inferred) | Sourced build-versus-buy receipts, as an agent skill. | `npx @pointbits/inferred install` |
| [**nah.**](https://github.com/pointbits/nah) | Not another harness: a lean execution layer for coding CLIs. | `npm i @pointbits/nah-sdk` |
| [**assembled.**](https://github.com/pointbits/assembled) | A TypeScript compiler written in x86-64 assembly. | GitHub releases |

**Platforms.** macOS is the primary target. The first releases were stress-tested and release-hardened on macOS and nowhere else. Linux and Windows are in beta: they should mostly work, but they haven't had that pass yet and may not be fully supported. assembled. is the exception that proves the rule: its binary only runs on Linux x86-64, and its macOS workflow builds and tests it through Docker.

## The idea

- **Useful first.** The joke is in the presentation, not the quality of the work.
- **Small by intent, not by potential.** A focused tool can have a large audience.
- **A little personality.** Dry, matter-of-fact, occasionally absurd. Never forced.
- **Loose affiliation.** Share a sensibility, not an obligatory design system.
